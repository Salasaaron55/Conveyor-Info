Navigation
  • Drag the map background to pan
  • Ctrl + scroll to zoom in/out
  • Click the minimap to jump to that area
  • Drag on the minimap to scroll the view live
  • Use zoom buttons or + / − controls in the toolbar
Selecting Conveyors
  • Click a conveyor to view its details in the Info tab
  • Ctrl + click a conveyor to instantly copy its alias
  • Click Center on map to scroll to the selected conveyor
Info Tab
  • Click any value cell to copy it to your clipboard
  • Use Copy all to copy all fields at once
Search
  • Type in the search box to highlight matching conveyors
  • Press Enter to select the first match
  • Use ↑ / ↓ to cycle through matches
  • Press Escape to clear the search
Notes Tab
  • Select a conveyor, then switch to Notes to add notes
  • Click Save Note to persist your note locally
  • Use Export All to download all notes as a JSON file
  • Use Import to load a previously exported JSON file
  • Notes are stored in your browser's local storage
Settings Tab
  • Switch between Dark and Light themes
  • Customize fill, border, and text colors for each conveyor type
  • Toggle the Legend and Minimap on or off
  • Use Reset to Defaults to restore original colors and theme
